# Nano Particle Size Analysis Simulation

This Python script simulates the fundamental concept of Nanolytica by generating and analyzing the size distribution of nano-particles. It provides basic statistical insights into the simulated nano-scale material characteristics.

## Language

`python`

## How to Run

Save the code as `nanolytica_sim.py` and run it from your terminal using `python nanolytica_sim.py`.
